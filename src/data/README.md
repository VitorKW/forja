# Dados

`taco.json` vem da Tabela Brasileira de Composição de Alimentos (TACO, 4ª edição, NEPA/UNICAMP, 2011), na versão em JSON de [marcelosanto/tabela_taco](https://github.com/marcelosanto/tabela_taco) (licença MIT).

Cada linha é `[nome, categoria, kcal, proteína, carboidrato, gordura]`, por 100 g. Itens sem valor de energia ou proteína ficaram de fora; traços ("Tr") viraram 0.
